# Multi-copy Pocket 정의 — 핵심 기여

> 이 문서는 이 프로젝트에서 가장 까다로웠던 엔지니어링 문제와 해결을 정리합니다.

## 배경

co-folding 모델은 "단백질 + 리간드 N copy + Zn"을 한 번에 접어 **한 구조 안에 N개의 리간드**를 배치합니다. 이 예측 구조들(3모델 × 30 = 90개/binder)에서 "리간드가 어디에 뭉치나 = 결합 pocket"을 찾아야 합니다.

## 문제 — 평균이 만드는 허공 pocket

결합 위치를 **리간드 원자 전체의 무게중심 1개**로 잡는 게 가장 단순한 방법입니다. 리간드가 1개면 잘 맞지만, multi-copy에선 이 방식이 깨집니다.

```
single-copy: 리간드 1개 → 무게중심 1개 = 그 리간드 위치 ✅
multi-copy : 리간드 4개(4곳) → 전 원자 평균 1개 = 4곳의 중점 = 허공 ❌
```

4개 copy가 단백질 표면 여기저기(예: 아연부위·exosite들)에 흩어져 있는데 그걸 평균내면, **아무 리간드도 없는 중간 지점**이 "pocket"으로 잡힙니다. 결과적으로 multi-copy binder는 전부 엉뚱한 위치가 pocket으로 나왔습니다.

## 진단 — 근거 데이터

p2rank(druggable cavity 예측)와 대조했을 때, multi-copy pocket들의 cavity 거리가 **전부 동일한 엉뚱한 값**(예: 9.39Å)으로 나온 게 결정적 단서였습니다. pocket마다 위치가 다르면 거리도 달라야 하는데 다 같다 → **하나의 병합 중점을 재고 있다**는 뜻.

## 해결 — copy별 무게중심 + 번호 무시 클러스터링

```
① 한 구조에서 리간드 copy를 잔기 단위로 분리
② copy마다 무게중심(점)을 따로 추출   →  구조당 N점 (copy 자리 보존)
③ 모든 구조의 점을 한 통에 (copy 번호는 버림 — 위치만)
④ 위치 기반 그리디 클러스터링 (8Å)   →  점이 뭉친 곳 = 진짜 pocket
```

핵심 코드 (`pipeline_core/2_pocket_candidates.py`):

```python
cens = cio.cached_copy_centroids(r["cif"], cache)   # 4-copy면 centroid 4개
if cens:
    for ac in geom.apply_rt(rt[0], rt[1], cens):
        data.append((r, ac))          # 구조당 copy 수만큼 '점' 추가
else:
    data.append((r, coords.mean(0)))  # 순진한 방식(전 원자 평균 1점) — 폴백으로만
```

### 왜 copy 번호를 버리나
모델마다 copy에 매기는 번호가 제각각(pt2=`l01`, bt2=`LIG1`, af3=`LIG_B/C/D`)이라, 번호로 매칭하면 깨집니다. **번호를 무시하고 위치로만 클러스터링**하면, 어느 모델의 몇 번 copy든 **같은 자리에 온 점끼리** 자동으로 묶여 pocket이 됩니다 → 모델 간 naming 차이에 견고.

## 검증 — 숫자가 증명

L010462(copy=4) 기준:

| 지표 | 값 | 의미 |
|---|---|---|
| copy-점 수 | 90구조 × 4 = **360점** | 구조당 4점 (병합 아님) |
| members.csv에서 한 구조 등장 | **4번** | 4 copy가 각각 다른 pocket에 배정 |
| pocket p2rank 거리 | P1 3.68 / P2 2.85 / P4 1.03 / **P5 21.19** | pocket마다 다른 값 = 제대로 측정 (P5=artifact) |

병합 중점이었다면 모든 pocket이 같은 거리였을 텐데, **각자 다른 값** = per-copy 방식이 작동한 직접 증거입니다.

## 배운 점

- ML 예측 구조를 다룰 때, single-copy 가정이 파이프라인 곳곳에 숨어있음 → multi-copy로 확장하려면 **기하 계산의 단위(구조 vs copy)**를 명시적으로 재정의해야 함.
- 모델 간 표기 불일치는 **타입 기반 식별 + 위치 기반 클러스터링**으로 흡수하는 게 견고함.
- "값이 다 똑같다"는 종종 **잘못된 대상을 재고 있다**는 신호.
